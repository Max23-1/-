# 大狗叫（uni-app）

一个简单的 uni-app 安卓软件：点击大狗图片，会切换成"大狗叫"图片，同时"叫"字向四周弹射，并播放狗叫音频。

## 项目结构

```
大狗叫app/
├── App.vue                 # 应用入口
├── main.js                 # 入口 JS（Vue 3）
├── manifest.json           # 应用配置（安卓权限、名称等）
├── pages.json              # 页面路由 + 底部 tabBar 配置
├── uni.scss                # 全局样式变量
├── pages/
│   ├── index/index.vue     # 页面1：大狗叫（核心功能）
│   ├── about/about.vue     # 页面2：大狗介绍
│   └── record/record.vue   # 页面3：叫声记录（计数 + 清零）
└── static/                 # 静态资源
    ├── 大狗1.webp          # 平时的大狗图片
    ├── 大狗叫.webp         # 叫的时候的大狗图片
    └── 大狗叫_爱给网_aigei_com.mp3   # 狗叫音频
```

## 功能说明

1. **页面1（大狗叫）**：点击大狗图片或「叫一声」按钮 → 图片切换 + 播放音频 + "叫"字向四周弹射。
2. **页面2（大狗介绍）**：展示大狗图片和文字介绍（使用了图片、文字标签、按钮组件）。
3. **页面3（叫声记录）**：统计累计叫声次数，可刷新、清零（使用本地存储 `uni.setStorageSync`）。

共 3 个页面，包含图片、按钮、文字标签等组件，并实现了切换图片、播放音频、动画弹射、计数存储等简单功能。

## 如何打包成安卓 APK

需要安装 [HBuilderX](https://www.dcloud.io/hbuilderx.html)（DCloud 官方 IDE）。

1. 打开 HBuilderX → 菜单「文件」→「导入」→「从本地目录导入」，选择本 `大狗叫app` 文件夹。
2. 首次云打包需要在 `manifest.json` 里填写 **DCloud AppID**（点「重新获取」自动生成）。
3. 菜单「发行」→「原生App-云打包」。
4. 勾选「Android」，选择「使用云端证书」或「公共测试证书」，点「打包」。
5. 等待打包完成，下载生成的 `.apk` 文件安装到安卓手机即可。

> 也可以先在浏览器预览效果：HBuilderX 里点「运行」→「运行到浏览器」（H5 模式）。
